# راندوم شات (RandomVid) — منصة دردشة فيديو عشوائية فورية (WebRTC + Socket.io)

منصة ويب متكاملة لدردشة الفيديو والمحادثة النصية العشوائية الفورية باللغة العربية، مبنية باستخدام **WebRTC** للاتصال المرئي والصوتي المباشر من الند للند (Peer-to-Peer) و **Node.js + Express + Socket.io** لخادم الإشارات والمطابقة الذكية.

---

## المميزات الرئيسية

* **اتصال فيديو وصوت حقيقي عبر WebRTC**: بث مباشر منخفض التأخير مع إعدادات خوادم STUN جاهزة ودعم إضافة خوادم TURN للإنتاج.
* **خادم مطابقة ذكي (Socket.io Matchmaking)**:
  * مطابقة عشوائية فورية في طابور الانتظار (`waitingQueue`).
  * مطابقة مخصصة حسب **الاهتمامات المشتركة** (`#العاب`، `#برمجة`، `#تقنية`، إلخ).
  * منع إعادة المطابقة مع الأشخاص الذين تم الإبلاغ عنهم في نفس الجلسة.
* **ثلاثة أوضاع تشغيل مدمجة في الواجهة الأمامية**:
  1. **وضع WebRTC المباشر (الخادم الحقيقي)**: يتصل تلقائياً بخادم `Socket.io` عند تشغيل المشروع عبر Node.js.
  2. **وضع المحاكاة الذكية**: يعمل تلقائياً في حال فتح ملف الواجهة بدون خادم لتجربة التصميم والمحادثة.
  3. **وضع P2P المحلي بين التبويبات**: يسمح بتجربة الاتصال بين نافذتي متصفح على نفس الجهاز عبر `BroadcastChannel`.
* **أدوات الخصوصية والأمان**:
  * درع حجب الفيديو التلقائي أو اليدوي (Anti-NSFW Blur Shield).
  * نظام إبلاغ وحظر فوري للمستخدمين المخالفين.
  * فلاتر فيديو مباشرة، عكس المرآة، ومشاركة الشاشة (`getDisplayMedia`).
  * اختصار لوحة المفاتيح `Esc` للانتقال السريع إلى شريك جديد.

## أولاً: تشغيل المشروع محلياً على جهازك

1. **فك ضغط الحزمة** `random-video-chat-webrtc.zip` وافتح الطرفية (Terminal) داخل مجلد المشروع.
2. **تثبيت الاعتماديات**:
   ```bash
   npm install
   ```
3. **تشغيل الخادم**:
   ```bash
   npm start
   ```
4. **فتح المنصة في المتصفح**:
   افتح الرابط `http://localhost:3000` في نافذتين مختلفتين (أو جهازين على نفس الشبكة) واضغط **"ابدأ المطابقة الآن"** لتجربة اتصال الفيديو المباشر عبر WebRTC.

## ثانياً: خطوات رفع المشروع مباشرة إلى مستودعك (`git push`)

بما أن المستودع البعيد خاص بحسابك على GitHub أو GitLab، يمكنك رفعه بطريقتين:

### الطريقة الأولى: الرفع السريع عبر السكربت المرفق (بأمر واحد)

* **على أنظمة Linux / macOS / Git Bash**:
  ```bash
  chmod +x push-to-git.sh
  ./push-to-git.sh https://github.com/YOUR_USERNAME/YOUR_REPO.git
  ```
* **على نظام Windows (Command Prompt / PowerShell)**:
  ```cmd
  push-to-git.bat https://github.com/YOUR_USERNAME/YOUR_REPO.git
  ```

### الطريقة الثانية: أوامر Git اليدوية خطوة بخطوة

نفّذ الأوامر التالية داخل مجلد المشروع بعد فك الضغط:

```bash
# 1. تهيئة مستودع Git محلي جديد
git init

# 2. تسمية الفرع الرئيسي main
git branch -M main

# 3. إضافة جميع ملفات المشروع
git add .

# 4. حفظ التغييرات في Commit أولي
git commit -m "feat: add full WebRTC and Socket.io random video chat project"

# 5. ربط المشروع برابط مستودعك (استبدل الرابط برابط مستودعك الفعلي)
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# 6. رفع الملفات إلى المستودع
git push -u origin main
```

> **ملاحظة في حال كان المستودع يحتوي على ملفات مسبقة (مثل README أو LICENSE)**:
> استخدم الأمر التالي لدمج التاريخ قبل الرفع:
> ```bash
> git pull origin main --allow-unrelated-histories
> git push -u origin main
> ```

## ثالثاً: نشر المشروع على الإنترنت (لدعم الكاميرا HTTPS)

يتطلب متصفح الويب اتصالاً آمناً (`HTTPS`) للسماح بالوصول إلى الكاميرا والميكروفون (`getUserMedia`) عند فتح الموقع عبر الإنترنت (باستثناء `localhost`). بعد رفع الكود إلى GitHub، يمكنك نشره مجاناً خلال دقيقة واحدة:

1. **النشر على منصة Render.com**:
   * سجل الدخول في Render واختر **New +** ثم **Web Service**.
   * اربط مستودع GitHub الذي رفعت المشروع إليه.
   * سيتعرف Render تلقائياً على ملف `render.yaml` (`Build Command: npm install` و `Start Command: npm start`).
   * اضغط **Create Web Service** لتحصل على رابط `https://your-app.onrender.com` يعمل بـ WebRTC و Socket.io مباشرة.
2. **النشر على منصة Railway.app أو Fly.io**:
   * المشروع يحتوي على ملف `Dockerfile` جاهز للنشر الفوري على أي خدمة سحابية تدعم حاويات Docker أو Node.js.
